# People · 人员档案

> 存放发哥日常接触人员的完整档案。命名：`people/{nickname-lowercase}.md`。
> hot cache 放最常用的 ~30 人；其余落这里。
> 维护规则见 `.claude/skills/memory-management/SKILL.md`。

## 使用约定

- 文件名：`people/<first-name-lowercase>.md`（如 `todd.md`、`sarah.md`）
- 常用联系人 → 同步到 `../CLAUDE.md` 的 People 表格
- 每次对话遇到新联系人，问清：姓名 / 角色 / 团队 / 联系方式偏好 / 备注

## 模板

```markdown
# <姓名>

**Also known as:** <昵称 / 别名>
**Role:** <角色>
**Team:** <团队>
**Reports to:** <上级>

## Communication
- 偏好渠道：<Slack / 微信 / 钉钉 / 邮件>
- 回复风格：<直接 / 慢热 / 详尽 / 简洁>
- 最佳联系时段：<时段>

## Context
- 负责 <职责>
- 关键决策权：<范围>
- 协作关系：<跟哪些团队/项目有关联>

## Notes
- <其他备注>
```
