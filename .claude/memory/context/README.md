## 使用约定

- 文件名：`context/<topic>.md`（如 `company.md`、`team-platform.md`、`tools.md`、`processes.md`）
- 频繁查的 → 同步到 `../CLAUDE.md` 的对应小节

## 建议拆分（按需建文件）

- `company.md` — 公司概况 / 业务方向
- `tools.md` — 内部工具 / 平台 / 凭据位置
- `team-platform.md`、`team-finance.md` 等 — 团队档案
- `processes.md` — 内部流程（周会 / 发版 / 审批）
