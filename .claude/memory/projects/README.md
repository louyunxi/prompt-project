# Projects · 项目档案

> 存放当前 / 历史项目的完整档案。命名：`projects/<project-slug>.md`。
> hot cache 只放 Project 的 5-15 个活跃项目；其余落这里。
> 维护规则见 `.claude/skills/memory-management/SKILL.md`。

## 使用约定

- 文件名：`projects/<project-slug>.md`（如 `app-prompt.md`、`phoenix.md`）
- 活跃项目 → 同步到 `../CLAUDE.md` 的 Projects 表格
- 项目完成 / 停摆 → 从 hot cache 移除（demote），文件保留在此
